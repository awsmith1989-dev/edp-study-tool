# Migrations

in order, in the Supabase dashboard's SQL Editor against the production
database before deploying the matching app code.

- `0001_license_type.sql` — beta mode
- `0002_cert_pathway.sql` — certification pathway question
- `0003_question_flags.sql` — per-question flagging
- `0004_survey_responses.sql` — in-app survey
